# Sample Application Package: AI Systems Engineer

This directory is an illustrative demo package showing the structure generated by `career_os_draft_application`.

## Contents
- `cover-letter.html`: Semantic HTML source for the tailored cover letter.
- `cover-letter.pdf`: Verified 1-page ATS-compliant PDF letter.
- `resume.pdf`: Verified 2-page ATS-compliant CV.
- `README.md`: Package documentation and review checklist.

## Safety Note
This sample package is for demonstration and automated testing only. It does not modify `job_search_tracker.csv`.
